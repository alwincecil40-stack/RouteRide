# RouteRide Flutter V1

A Flutter Android starter app converted from the RouteRide web prototype.

## Run
1. Install Flutter SDK and Android Studio.
2. In this folder run:
   flutter pub get
   flutter run

## Current V1
- Customer trip planner
- Pickup/drop-off
- Travel date and passengers
- Add/remove destinations
- Vehicle selection
- Demo fare calculation
- Route preview
- Request quotation button
